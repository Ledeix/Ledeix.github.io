Turning Safety into Competence: Minimally Exploitable Robot Policies via Safety-Filtered Reinforcement Learning

Ruihan Wu*, Rui Yang*, Donggeon David Oh, Duy P. Nguyen, and Haimin Hu

arXiv preprint arXiv:2609.27312, 2026  ·  *Equal contribution

arXiv HTML PDF Website Code

We propose Safety to Competence (S2C), a two-stage reinforcement learning framework that separates safety synthesis from competitive task learning. S2C learns a robust safety filter through adversarial RL, embeds it during task-policy training, and retains it at deployment. In simulated touchdown games and hardware stress tests against a human opponent, S2C improves competitive performance and reduces exploitability while maintaining safety.

Deep Hydro-Sim: Structured Residual Hydrodynamics for the RL-Based AUV Control

Ruihan Wu, Chunying Li, Qirong Lei, Le Huang, Pengcheng Li, and Shuxiang Guo

2026 IEEE International Conference on Mechatronics and Automation (ICMA), pp. 1526–1531, 2026

DOI IEEE

Deep Hydro-Sim is a hybrid Stonefish–MuJoCo framework for reinforcement-learning-based autonomous underwater vehicle control. It transfers residual hydrodynamic forces from a high-fidelity underwater simulator into a fast rigid-body simulator through a real-time physics plugin and a physics-informed residual model, improving hydrodynamic fidelity while preserving the throughput needed for RL training.
